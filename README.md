# Tanveer Shikalkar – Portfolio

Static portfolio site (no build needed).

## Publish on GitHub Pages
1. Create a repo named `tanveershikalkar.github.io` (or any name).
2. Upload `index.html` and the resume file to the repo root.
3. Repo → Settings → Pages → Source: "Deploy from a branch" → `main` / root → Save.
4. Site goes live at `https://<username>.github.io/` (or `/<repo>/`) in about a minute.
